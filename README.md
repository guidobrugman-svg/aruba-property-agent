# Aruba Property Agent

Automated monitoring of Aruba real-estate listings.

## Purpose

Monitor qualifying Aruba properties for:

- New listings
- Price reductions
- Major listing changes

## Property criteria

- For sale only
- Maximum price: $650,000 USD
- Commercial buildings excluded
- Rentals excluded
- Vacation rentals excluded
- Sold/pending/withdrawn properties excluded

## Property types

Includes houses, villas, apartments, condos, townhouses, land,
developments/new construction, multi-unit properties and other
qualifying real-estate investments.

## Monitoring

Target monitoring interval: approximately every 5 minutes.

## Alerts

- New qualifying properties
- Price reductions
- Major changes
- 30-minute batching where appropriate
- Daily digest at 08:00 Aruba time
